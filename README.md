# Keystroke Tracker

This application tracks the number of keystrokes in real-time using a GUI.

## Requirements

- Python 3.x
- pynput library

## Installation

1. Install dependencies: `pip install -r requirements.txt`

## Usage

Run the desktop application: `python main.py`

Run the web UI: `python app.py`, then open `http://localhost:5000` in your browser.

Click "Start Tracking" to begin counting keystrokes.

Click "Stop Tracking" to stop.

The count is displayed in real-time.

Note: On Windows, you may need to run as administrator for global key tracking.
